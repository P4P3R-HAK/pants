# 불법 사이트 탐지기

브라우저에서 열고 있는 웹페이지를 분석해서, 위험 점수가 설정한 기준을 넘으면 즉시 차단하는 Chrome 확장프로그램입니다.  
단순 문자열 필터링이 아니라 페이지 구조를 정제해서 보고, 원격 분류기와 로컬 규칙을 함께 사용하도록 만든 것이 핵심입니다.

## 프로젝트 개요

이 프로젝트는 "브라우저 단에서 최대한 빠르게 의심 사이트를 걸러내자"는 목적에서 출발했습니다.

- 현재 열려 있는 URL을 정제해서 분석 대상으로 사용하고
- 페이지의 제목, 헤딩, 링크, 폼, 가시 텍스트를 스냅샷으로 축약한 뒤
- 원격 분류기 또는 로컬 휴리스틱 규칙으로 위험도를 계산하고
- 사용자가 정한 차단 기준을 넘으면 차단 페이지로 전환합니다

차단 이후에도 사용자는 이번만 허용, 항상 신뢰, 뒤로 가기 같은 대응을 직접 선택할 수 있습니다.


## 현재 구성

- `manifest.json`
  확장프로그램 메타데이터와 권한, 팝업, 사이드 패널 진입점을 관리합니다.
- `background.js`
  검사 요청 수신, 원격 분석 호출, 로컬 규칙 평가, 차단 처리, 배지 갱신, 검사 이력 관리, 신뢰/세션 허용 관리의 중심입니다.
- `content.js`
  현재 페이지에서 분석용 스냅샷을 만들고, SPA 이동이나 의미 있는 DOM 변화가 생기면 다시 검사를 요청합니다.
  설정이 바뀌어도 현재 탭을 강제로 다시 검사할 수 있게 처리했습니다.
- `popup.html` / `popup.js` / `styles.css`
  빠른 제어용 팝업입니다. 실시간 차단 on/off, 차단 기준 조절, 현재 사이트 신뢰, 재검사, 대시보드 열기를 제공합니다.
- `sidepanel.html` / `sidepanel.js` / `sidepanel.css`
  확장프로그램의 메인 대시보드입니다. 현재 탭 상태, 최근 검사 기록, 신뢰 사이트, 세션 허용 목록을 관리합니다.
- `blocked.html` / `blocked.js` / `blocked.css`
  차단 화면입니다. 위험 점수와 탐지 근거를 보여주고, 뒤로 가기 / 이번만 허용 / 항상 신뢰 흐름을 처리합니다.
- `rules.json`
  원격 분석이 꺼져 있거나 실패했을 때 사용할 로컬 휴리스틱 규칙입니다.

## 보안적인 요소

- 원격 분석은 안전한 엔드포인트에서만 동작합니다.
  현재처럼 `http://...` 형태의 비보안 주소는 자동으로 차단됩니다.
- `localhost`, 사설 IP, `.local` 같은 내부 주소는 원격으로 보내지 않습니다.
- 전체 `outerHTML`을 그대로 전송하지 않고, 분석에 필요한 구조만 정리한 스냅샷을 사용합니다.
- URL의 쿼리스트링, 해시, 인증 정보는 제거합니다.
- 이메일, 카드번호처럼 보이는 문자열과 긴 토큰 문자열은 전송 전에 마스킹합니다.
- 차단 페이지 상태는 URL 파라미터에 직접 싣지 않고, 일회성 토큰으로 조회합니다.
- 세션성 데이터는 `chrome.storage.session`에 분리해서 브라우저 세션이 끝나면 자연스럽게 정리되도록 했습니다.

## 동작 방식

1. 사용자가 페이지를 열면 `content.js`가 분석용 스냅샷을 생성합니다.
2. `background.js`가 로컬 규칙을 먼저 평가하고, 조건이 맞으면 원격 분류기에도 요청합니다.
3. 최종 위험 점수를 계산한 뒤 설정 임계치와 비교합니다.
4. 기준을 넘으면 차단 페이지로 이동하고, 넘지 않으면 최근 검사 상태와 배지를 갱신합니다.
5. 팝업과 사이드 패널에서는 현재 상태 확인, 기준 조정, 신뢰/세션 허용 관리가 가능합니다.
6. 차단 페이지가 열려 있는 상황에서도 팝업과 대시보드는 원본 사이트 기준으로 다시 검사하거나 신뢰 처리할 수 있습니다.

## 실행 방법

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 우측 상단의 개발자 모드를 켭니다.
3. `압축해제된 확장 프로그램을 로드`를 눌러 `pants-main` 폴더를 선택합니다.
4. 확장프로그램 아이콘을 눌러 팝업을 확인하고, `보안 대시보드` 버튼으로 사이드 패널을 열어 동작을 점검합니다.
